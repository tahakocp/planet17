# Contributing

The most useful thing you can send is a print report: printer, nozzle, material, layer height, the `backlash` and `fit` values that worked, whether it ran, and a photo. Open a "Print report" issue.

For code changes:

- Run `scripts/check.sh` (both presets, about 20 s) before opening a PR. If you change gear geometry, say what you changed in the clash numbers.
- Keep `scad/gear.scad` free of dependencies. If a change needs BOSL2 or similar, open an issue first.
- A new ratio preset needs to pass the sweep and the negative controls. Add it to `presets/planet17.json` and to the preset list in `scripts/build.sh` and `scripts/check.sh`.
- `stl/` is generated by `scripts/build.sh`. Regenerate it in the same commit as a design change.
- Plain, short commit messages. One change per PR.

Parts are CERN-OHL-P-2.0; by contributing you agree yours are too.
